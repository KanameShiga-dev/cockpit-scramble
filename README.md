# MoonBase

スマホの傾きセンサーとカメラを使った、360°ワイヤーフレームHUDの戦闘ゲームです。
HTMLファイル1つと機体画像（`img/`）で動き、外部サーバーやビルドは不要です。

## 公開手順（GitHub Pages）

傾きセンサーとカメラは、HTTPSの単独ページでないと動きません。以下の手順で公開してください。

1. GitHubで新しいリポジトリを作成する（Public）
2. `index.html` と `img` フォルダをアップロードする（「Add file」→「Upload files」）
3. 「Settings」→「Pages」を開き、Branch を `main`、フォルダを `/ (root)` にして保存する
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` をスマホで開く

### うまく動かないとき

- **iPhoneで傾きが効かない**：出撃ボタンを押したときに出る「動きと画面の向き」の許可ダイアログで「許可」を選んでください。一度拒否すると再表示されないため、「設定」→「Safari」→「詳細」→「Webサイトデータ」から該当サイトのデータを削除して、もう一度開いてください。
- **Androidで傾きが効かない**：Chromeの「サイトの設定」→「モーションセンサー」が許可になっているか確認してください。
- **カメラが映らない**：カメラの許可を確認してください。使えない場合もCG背景で遊べます。
- **claude.ai上で開いた場合**：埋め込み表示の制約でセンサーが使えないことがあります。その場合はドラッグで視点を動かせます。

## 遊び方

1. タイトル画面で START を押し、出撃画面で機体・難易度・旋回感度を選んで「出撃」を押す
2. スマホを持って体ごと向きを変え、敵を探す
3. 敵を1回タップすると識別（モニターにスペックと全身図が出る）
4. 同じ敵をもう1回タップすると捕捉
5. 捕捉した敵を照準の円に入れると、距離に応じた武器で自動攻撃する

### 画面の見方

スマホを横向きにすると、コンソールが右側に移り、左側全体がメインモニターになります。

- **矢印**：画面外の敵の方向。赤＝近距離（150m未満）、黄＝中距離（500m未満）、緑＝遠距離
- **レーダー**（コンソール左）：上が正面。リングは近・中・遠の境界。左上の人型は自機の損傷状態
- **モニター**（コンソール右）：識別または捕捉した敵のスペック、距離、行動（強襲・奇襲・回避）
- **ゲージ**：装甲、EN（射撃エネルギー）、燃料

### ロックオン警告と回避

敵は撃つ前にこちらをロックオンします（約1秒、ボスは約1.4秒）。そのあいだ画面上部に「LOCK-ON WARNING」と方向が出て、回避ボタンが赤く点滅します。回避ボタンを押すとロックオンが外れ、その攻撃は当たりません。

| 機体 | 回避行動 | 再使用まで |
|---|---|---|
| ZX-01 | 回転しながら横へ避ける | 4秒 |
| HV-02 | 後方へダッシュ（敵との距離が開く） | 6秒 |
| SN-03 | 前方へダッシュ（敵との距離が詰まる） | 2.5秒 |

### ボタン

| ボタン | 動作 |
|---|---|
| 回避 | 機体ごとの回避行動（燃料10消費）。敵のロックオンを外して攻撃をかわす。使うと一定時間使えない |
| 離脱 | 2回続けて押すと作戦から離脱し、タイトル画面に戻る |
| 正面 | 今向いている方向を旋回の基準に設定し直す |
| 背景 | 映像／輪郭／CG を切り替える（地上戦域のみ） |
| 音 | 効果音のオン・オフ |

ジャイロ使用中でも、ドラッグで視点を補正できます。PCでは矢印キーでも操作できます。

## 機体

機体の性能は三面図の印象に合わせています。

| 機体 | タイプ | 装甲 | 同時捕捉 | 近距離 | 中距離 | 遠距離 |
|---|---|---|---|---|---|---|
| ZX-01 エアロウィング | TYPE-A バランス | 110 | 3 | ビームサーベル | ビームライフル | ロングビームキャノン |
| SN-03 ニードル | TYPE-B スピード | 80 | 2 | ビームダガー（連撃） | 連装ビームSMG | ビームライフル |
| HV-02 バスティオン | TYPE-C パワー | 170 | 4 | ヒートアックス | ガトリング | ツインキャノン |

- 中・遠距離の武器はENを消費します。ENが足りないときはバルカンに切り替わります。
- 捕捉中の敵が照準の円に複数入っていると、ENが続く限り同時に撃ちます。
- 捕捉済みの敵をタップすると、その敵が主目標になります。

## 難易度

出撃画面で EASY / NORMAL / HARD を選べます。選んだ難易度は端末に保存され、次回も使われます。

| 項目 | EASY | NORMAL | HARD |
|---|---|---|---|
| 敵の耐久 | 0.5倍 | 0.8倍 | 1.35倍 |
| 被ダメージ | 0.4倍 | 0.75倍 | 1.4倍 |
| ロックオンから発射まで | 1.8倍（長い） | 1.2倍 | 0.75倍（短い） |
| 敵の射撃間隔 | 1.6倍（長い） | 1.15倍 | 0.8倍（短い） |
| 1波の敵の数 | 2機少ない（最低1機） | 標準 | 1機多い |
| 制限時間 | 1.6倍 | 1.15倍 | 0.8倍 |

倍率は基準値に対するものです。NORMAL も基準値より少しやさしくしています。

## 部位破壊

装甲が20%減るごとに、次の順で部位が壊れます。

| 順 | 部位 | 影響 |
|---|---|---|
| 1 | 左脚 | 回避の再使用が遅くなる（1.6倍） |
| 2 | 右脚 | 回避でロックオンを外せる確率が70%に下がる |
| 3 | 左腕 | 格闘の威力が下がり、被弾しやすくなる |
| 4 | 頭部 | 照準マーカーが消え、モニターにノイズが乗る |
| 5 | 右腕 | 撃墜（ゲームオーバー） |

ステージを制圧すると装甲が25%回復しますが、壊れた部位は元に戻りません。

## 敵

| 機体 | 種別 | 得意な距離 | 特徴 |
|---|---|---|---|
| GR-7 ガルム | 量産型 | 中 | 標準的な相手 |
| VX-3 ヴェスパ | 高機動型 | 近 | 速く、接近して格闘してくる |
| HK-9 ホーク | 砲撃型 | 遠 | 硬く、遠くから撃ってくる |
| TX-0 タイタン | 大型陸戦機 | 中 | 地上戦域のボス。3連射 |
| FX-9 ハイヴ | 宇宙要塞 | 遠 | 宇宙戦域のボス。艦載機を発進させる |

敵は次の3つの行動を切り替えます。

- **強襲**：得意な距離まで詰めて攻撃する
- **奇襲**：背後に回り込んでから攻撃する（後方から撃たれると警報が鳴る）
- **回避**：被弾すると動きが激しくなり、射撃を一定確率でかわす

## ステージ構成

1. **地上戦域**：3波の後、タイタン戦
2. **宇宙戦域**：3波の後、ハイヴ戦
3. **巨大兵器破壊**：制限時間3分。巨大砲台「ゴライアス砲」を破壊する
   - 冷却装置2基が残っているあいだ、砲台は装甲で攻撃を防ぐ。先に冷却装置を壊す
   - 主砲の充填が100%になると2秒のロックオン後に発射（大ダメージ）。回避すれば外れる
   - 護衛機が増援で来る。時間切れは作戦失敗
4. **戦艦撃破**：宇宙戦艦「グラナート級」を撃沈する（制限時間なし）
   - 砲塔4基が残っているあいだ、艦橋は装甲で攻撃を防ぐ。砲塔は交代でロックオンして撃ってくる
   - 主砲は約25秒ごとに充填され、2秒のロックオン後に発射。回避すれば外れる
   - 艦載機が戦艦から発進してくる
5. **月面要塞へ**：追加装備を付けて再発進し、月面要塞への到達を目指す（敵の撃破は不要）
   - 出発前に、月の方向を計算するため現在地を使うか選ぶ（端末内の計算だけに使い、送信も保存もしない）。使わない場合やコンパスがない端末では、月を仮の方向に置く
   - 月が画面中央から20°以内にあるとブースターで加速する。迎撃機のロックオンは回避で外す
   - フルアーマー：装甲の50%の追加装甲が先にダメージを受け、尽きるとパージされる
6. **要塞侵入**（最終ステージ）：月面要塞の内部通路を進む
   - 区画1〜3：防衛機と壁面砲台をすべて倒すと隔壁が開き、次の区画へ前進する
   - 最深部：防御ジェネレーター3基を壊すとコアの装甲が弱まる。コアは主砲を充填して撃ってくる（回避可）
   - コアを破壊すると「月面要塞 陥落」。エンディング（パイロット名・機体・難易度・スコア・残り装甲・所要時間）を表示し、タイトル画面に戻る

撃墜・離脱・作戦失敗のときもタイトル画面に戻り、前回の結果がタイトルに表示されます。

### 途中のステージから始める（確認用）

URLの末尾に `?stage=番号`（1〜6）を付けると、そのステージから出撃します。例：`?stage=5` で月面要塞へ、`?stage=6` で要塞侵入から。

## 技術メモ

- 傾き：`deviceorientation`（iOS 13以降は `DeviceOrientationEvent.requestPermission()` をタップ内で呼ぶ）
- カメラ：`getUserMedia`（`facingMode: environment`、`<video playsinline muted>`）
- 輪郭モード：160px幅に縮小した映像にSobelフィルタをかけて描画
- 効果音：Web Audio APIでその場で合成（音声ファイルなし）
- 旋回感度：センサーの方位を連続値に展開してから倍率をかけるため、真後ろを越えても視点が跳ばない

機体名・敵機名はすべてオリジナルです。
